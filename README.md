# RealWorld Launcher

Windows WPF-лаунчер для Minecraft 1.21.4 с независимыми профилями.

## Возможности MVP
- несколько профилей с отдельными папками игры и RAM;
- пресеты RealWorld / Мега гриф / Анархия и свой адрес;
- прокси-поле для профиля;
- настройки команд `/reg` и `/login`;
- отдельные процессы Java;
- кнопка открытия `mods`;
- подготовка self-contained Windows-сборки через `build.ps1`.

Для сборки нужен .NET 8 SDK на Windows: запусти `powershell -ExecutionPolicy Bypass -File .\build.ps1`. Для запуска укажи папку, где находится подготовленный клиент и Java 21. Не добавляй пароли в репозиторий: конфигурация лаунчера хранится локально и не коммитится.

Прокси в MVP сохраняется в профиле как настройка для совместимого клиента/мода; обычный vanilla-клиент Minecraft не принимает произвольный proxy из JVM-аргументов для игрового TCP-подключения. Для полноценного прокси нужен клиентский мод или локальный proxy-wrapper.

Автоматическая GitHub-сборка описана в `.github/workflows/build.yml`; если GitHub не принимает файл из API из-за scope `workflow`, создай этот файл через GitHub web UI или переподключи GitHub с разрешением Actions workflow.

Проект предназначен для разрешённого использования на серверах. В нём нет обхода античита, инъекций в Minecraft или скрытия автоматизации.
