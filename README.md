# RealWorld Launcher

Windows WPF-лаунчер для Minecraft 1.21.4 с независимыми профилями.

## Возможности MVP
- несколько профилей с отдельными папками игры и RAM;
- пресеты RealWorld / Мега гриф / Анархия и свой адрес;
- прокси-поле для профиля;
- настройки команд `/reg` и `/login`;
- отдельные процессы Java;
- кнопка открытия `mods`;
- автоматическая Windows-сборка через GitHub Actions.

Для запуска укажи папку, где находится подготовленный `minecraft.jar`/клиент и Java 21. Не добавляй пароли в репозиторий: конфигурация лаунчера хранится локально и не коммитится.

Проект предназначен для разрешённого использования на серверах. В нём нет обхода античита, инъекций в Minecraft или скрытия автоматизации.
